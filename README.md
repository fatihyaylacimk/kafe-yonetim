## 📸 Özellikler

| Modül | Açıklama |
|---|---|
| 📊 **Genel Bakış** | Günlük gelir, aktif sipariş sayısı, haftalık gelir grafiği |
| 🍽 **Dijital Menü** | Ürün ekle/sil, fiyat, açıklama, kampanya, QR menü önizlemesi |
| 🧾 **Sipariş Takip** | Masa seç → ürün ekle → mutfağa gönder → tamamla akışı |
| 📦 **Stok Takip** | Malzeme yönetimi, düşük stok uyarısı, otomatik güncelleme |
| 📈 **Satış Raporu** | Günlük/haftalık gelir, saatlik yoğunluk, en çok satılan ürünler |
| ⭐ **Sadakat Sistemi** | Puan kazanma, 100 puan = ücretsiz kahve, müşteri kaydı |
| 📅 **Rezervasyon** | Masa rezervasyonu, onay/iptal yönetimi |
| 👥 **Personel Takip** | Vardiya, maaş, izin ve durum yönetimi |
| 🌐 **Web Sitesi** | Kafenin profesyonel site önizlemesi |

## 🚀 Kurulum

### Telefon
1. `index.html` dosyasını indir
2. Dosya yöneticisinden bul → tarayıcıda aç
3. Tarayıcı menüsü → **"Ana Ekrana Ekle"** → uygulama gibi kullan

### Bilgisayar
1. `index.html` dosyasını indir
2. Çift tıkla → tarayıcıda açılır

### GitHub Pages ile Yayınlama
```
1. Bu repoyu fork'la veya klonla
2. Settings → Pages → Branch: main / (root) → Save
3. https://kullaniciadin.github.io/kafe-yonetim adresinde yayında
```

## ✏️ Özelleştirme

`index.html` dosyasını bir metin editörü ile açarak:

- **Kafe adı** → `KAFÉ SİSTEM` yazan yerleri değiştir
- **Adres / telefon** → Web Sitesi bölümündeki iletişim bilgilerini güncelle
- **Başlangıç menüsü** → `let menu = [...]` dizisini düzenle
- **Renkler** → `:root` içindeki CSS değişkenlerini değiştir
